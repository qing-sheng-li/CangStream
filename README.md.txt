A Streamlit-inspired web framework for building interactive applications using pure Cangjie language.

✨ Features
🎯 Pure Cangjie - No HTML/CSS/JavaScript knowledge required

🎨 Modern UI - Built-in beautiful gradient purple theme

🔄 Auto State Management - Automatic input persistence and synchronization

🚀 Rapid Development - Perfect for prototyping, demos, and internal tools

🧵 Thread-Safe - Mutex-protected state management

🌐 Built-in HTTP Server - Complete web service based on stdx.net.http
